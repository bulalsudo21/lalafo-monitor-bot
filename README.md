# 🔍 Lalafo.kg Price Monitor Bot

**Асинхронный Telegram-бот для мониторинга объявлений на Lalafo.kg через эмуляцию браузера.**

## 🚀 Быстрый старт

git clone https://github.com/ТВОЙ_ЮЗЕР/lalafo-monitor-bot.git
cd lalafo-monitor-bot
cp .env.example .env
nano .env
docker compose up -d --build

## 📋 Команды

| Команда    | Действие                  |
|------------|---------------------------|
| `/monitor` | Добавить фильтр           |
| `/stop`    | Удалить все фильтры       |
| `/list`    | Показать активные фильтры |
